# AuraFit AI — Android / Expo

This adds an Expo React Native Android app while keeping the original `aurafit_ai_pro.html` unchanged. The native app provides Routine, Weight, AI Studio, Hydration/Tips, bilingual Bangla/English UI, locally persisted tracking, Gemini coaching, and Android scheduled reminders.

## Run locally

Requirements: Node.js LTS, Android Studio + Android SDK (for local Android builds), and an Android device/emulator.

```bash
npm install
npx expo start
```

Scan the QR code with an Expo development build, or build/run a native development app:

```bash
npx expo prebuild --platform android
npx expo run:android
```

Expo Go is not suitable for validating native scheduled notifications. Use an Android development build or APK.

## APK / Play Store build

```bash
npm install -g eas-cli
eas login
eas build:configure
# Set the generated EAS project ID in app.json's extra.eas.projectId
npm run build:apk
npm run build:aab
```

`preview` produces an installable APK; `production` produces an AAB. APKs are generated by EAS Build, not committed to this source repository.

## Reminder timing on Android

The app requests notification permission, creates a high-importance reminder channel, and schedules each enabled reminder as a daily native notification. Android 12+ exact-alarm access is user-controlled; the app declares `SCHEDULE_EXACT_ALARM` and provides Android app settings from the Settings screen. For dependable delivery, enable **Alarms & reminders / exact alarms**, allow notifications, and disable battery restrictions for AuraFit on the device. Android OEM battery-management policies may still delay delivery. The app reconciles its reminder schedule at launch and when the app returns to foreground. Android's notification service retains scheduled alarms across ordinary reboots; opening the app after reboot also reconciles them.

Notifications are local and do not require the app to stay open. They are not medical advice. The AI API key is stored using Android Keystore-backed SecureStore; calls are made directly from the device, so the key is private to the device but still used by the client app. Never embed a personal key in source control.

## Data & original version

Routine, weight, hydration, and language preferences use AsyncStorage on this device. The Gemini key uses SecureStore. Data is not synchronized to a server. The original standalone web app remains at `aurafit_ai_pro.html`.
